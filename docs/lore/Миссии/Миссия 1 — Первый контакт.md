# Миссия 1 -- Первый контакт

> *"Это как включить свет в тёмной комнате. Ты не трогаешь ничего -- просто смотришь."*

## Акт 1: Пробуждение

Первая миссия игры. Введение в механику, философию [[Burunduk|burunduk'а]] и мир [[Полог (The Canopy)|Полога]]. [[Игрок]] -- новичок, burunduk ведёт за руку. Максимум подсказок, минимум давления. За обучающей оболочкой -- первая нить к глобальному заговору.

## Цель

**Организация:** [[NovaTech Solutions]]
**Целевая сеть:** `192.168.1.0/24`
**Тип:** Небольшая веб-студия, три человека в штате. Сайты для кафешек и зубных клиник. Серверы скомпрометированы [[Полог (The Canopy)|Пологом]] без ведома сотрудников -- используются как ретрансляционный узел.

## Задачи

1. **Разведка сети** -- `nmap 192.168.1.0/24` -- обнаружить хосты
2. **Сканирование рабочей станции** -- `nmap 192.168.1.10` -- найти уязвимый SSH
3. **Компрометация рабочей станции** -- `exploit ssh_enum_users 192.168.1.10` -- войти через OpenSSH 7.2
4. **Поиск учётных данных** -- найти `/opt/config.ini` с паролем к БД
5. **Подключение к серверу БД** -- `ssh dbadmin@192.168.1.20` с найденным паролем
6. **Скачивание конфигурации ретранслятора** -- `download /var/lib/mysql/customers.db`

## Реакции burunduk'а

Полный текст: [[Реакции миссия 1]]

### После сканирования сети

```
[burunduk]: Три хоста. Роутер, рабочая станция, сервер БД.
            Классическая маленькая сеть. Роутер нам не интересен.
            А вот рабочая станция -- это наша точка входа.
            Просканируй её подробнее.
```

### После компрометации рабочей станции

```
[burunduk]: Ты внутри. Первый взлом.
            ...Знаю, звучит странно. Не думал, что будешь
            таким заниматься, да?
            
            Не привыкай к ощущению. Это не игрушка.
            За каждым сервером -- живые люди.
            Мы здесь не ради азарта.
            
            Теперь ищи. Нам нужны данные для доступа к серверу БД.
```

### После прочтения конфига с паролем

```
[burunduk]: db_user: dbadmin, db_pass: S3cureDB!
            Пароль хранится в открытом тексте в конфиг-файле.
            На рабочей станции, доступной по SSH со слабым паролем.
            
            Знаешь, что самое грустное? Это не исключение.
            Это норма. Девяносто процентов взломов происходят
            потому что кто-то записал пароль на стикере.
            
            Попробуй этот пароль на сервере БД.
```

### После скачивания файла (завершение миссии)

```
[burunduk]: Есть. Файл у меня.
            
            ...Дай мне минуту.
            
            Хорошо. Это не просто база клиентов. Внутри --
            зашифрованная конфигурация. Ретрансляционные узлы,
            временные ключи, маршруты трафика.
            
            Кто-то использовал NovaTech как прокси.
            Данные проходили через их сервер дальше --
            в финансовую сеть. Crestfall Financial Services.
            
            Это наша следующая цель.
            
            {handle}, ты только что провёл свою первую
            настоящую операцию. Я бы соврал, если бы сказал,
            что не впечатлён.
            
            Отдохни. Когда будешь готов -- у меня есть
            кое-что новое для тебя.
```
