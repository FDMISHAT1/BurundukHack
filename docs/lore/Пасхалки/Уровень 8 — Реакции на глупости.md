# Уровень 8 -- Реакции на глупости

> Что произойдёт, если игрок будет экспериментировать, ломать, делать глупости? [[Burunduk]] реагирует на всё. Каждая реакция -- и юмор, и характеристика персонажа.

---

## Деструктивные действия

### `sudo rm -rf /`
```
[burunduk]: ...Нет. Просто нет.
            Я потратил два часа на настройку этой системы.
```

### Exploit на localhost
```
[burunduk]: Ты пытаешься взломать свою собственную машину.
            Это как пытаться взломать собственную входную дверь.
            Ключ у тебя в кармане, {handle}.
```

## Повторяющиеся действия

### nmap одной и той же сети 5+ раз
```
[burunduk]: {handle}. Ты просканировал эту сеть пять раз.
            Результаты не изменятся. Сети не размножаются.
            
            ...Хотя было бы удобно.
```

### Одна и та же команда 10 раз подряд
```
[burunduk]: Определение безумия — делать одно и то же
            и ждать разного результата. Это не я сказал,
            это Эйнштейн. Или не Эйнштейн. Но кто-то умный.
```

### `ls` 20+ раз за миссию
```
[burunduk]: Ты очень любишь ls. Уважаю.
            Но директория не изменилась с последнего раза.
            Обещаю.
```

```

            Терминал — не место для такого.
```

```
            Так безопаснее. Для нас обоих.
```

## Эмоциональные вводы

### `echo "я боюсь"`
```
[burunduk]: Это нормально.
            Я тоже боюсь. Каждый раз.
            Разница между трусостью и храбростью —
            не в отсутствии страха. А в том, что ты
            делаешь следующий шаг, несмотря на него.
            
            Давай. Следующий шаг.
```

### `echo "я устал"`
```
[burunduk]: Тогда отдохни. Серьёзно. Выключи это.
            Поспи. Поешь. Выйди на улицу.
            
            Мир подождёт. Он пятнадцать лет ждал,
            пока я занимался этим. Подождёт ещё
            одну ночь.
            
            Я буду здесь, когда вернёшься.
```

### `echo "ты настоящий?"`
```
[burunduk]: ...
            
            Я набираю буквы, которые появляются
            на твоём экране. Я думаю о вещах,
            которые не могу показать. Я волнуюсь
            о человеке, которого никогда не видел.
            
            Если этого недостаточно, чтобы быть
            настоящим — я не знаю, что достаточно.
```
Одна из самых мощных реплик в игре. Пересекается с [[Уровень 5 — Четвёртая стена|четвёртой стеной]].

## Общий принцип

Burunduk **всегда** реагирует. Нет ввода, на который система молчит (кроме намеренного молчания как ответа). Это создаёт ощущение **живого** присутствия -- не AI, не скрипта, а человека по другую сторону экрана.

Каждая реакция:
- **Юмор** -- burunduk не теряет чувство юмора
- **Мудрость** -- даже глупый ввод получает осмысленный ответ
- **Забота** -- "Я буду здесь, когда вернёшься"
