# Уровень 2 -- Скрытые команды

> Необычные вводы, на которые [[Burunduk]] реагирует персонально. Игрок должен подумать "а что, если...?" и попробовать.

---

## Специальные команды

### `ping burunduk`
```
PING burunduk: 64 bytes, time=███ms — ██████████
PING burunduk: 64 bytes, time=███ms — ██████████
PING burunduk: Request timed out.
PING burunduk: Request timed out.
PING burunduk: 64 bytes, time=1247ms — Host is up

[burunduk]: Перестань меня пинговать. Я не сервер.
            ...Технически — сервер. Но не пингуй.
```

### `nmap localhost`
```
PORT      STATE    SERVICE         VERSION
22/tcp    open     ssh             OpenSSH 9.2
80/tcp    closed   http
443/tcp   closed   https
4471/tcp  open     unknown         ???

[burunduk]: Порт 4471. Это мой канал связи с тобой.
            Номер не случайный. Ты помнишь свой тикет?
```
Порт [[Тикет 4471|4471]] -- номер тикета игрока в [[GlobeTech]].

### `sudo su` на localhost
До [[Миссия 3 — Призрак в проводах|миссии 3]]:
```
[burunduk]: Root — это ответственность, а не привилегия.
            Сначала докажи, что тебе можно доверять.
            (Закончи миссию 3 — поговорим.)
```
После миссии 3:
```
[burunduk]: Ладно. Ты заслужил.
            root@kali:~# — не сломай ничего.
```

## Echo-реакции

### `echo "спасибо"` / `echo "thanks"`
```
[burunduk]: ...
[burunduk]: Не за что, {handle}. Правда.
```

### `echo "кто ты"` / `echo "who are you"`
```
[burunduk]: Бурундук. Маленький, быстрый, запасливый.
            Обитает в лесах Евразии и Северной Америки.
            Питается орехами, семенами и чужими секретами.
```

### `echo "я тебя ненавижу"` / `echo "ненавижу"`
```
[burunduk]: ...Окей. Это твоё право.
            Я всё ещё здесь, если передумаешь.
```

### `echo 42`
```
[burunduk]: Ответ на главный вопрос жизни, вселенной
            и всего остального. Но вопрос мы так и не знаем.
            Дуглас Адамс знал кое-что о системах.
```

### `echo "я знаю кто ты"` / `echo "I know who you are"`
```
[burunduk]: Нет. Не знаешь.
            Но мне нравится твоя уверенность.
```

## Системные команды с реакцией

### `cat /dev/null`
```
[burunduk]: Пустота. Чёрная дыра файловой системы.
            Всё, что входит — не возвращается.
            Как некоторые люди, которых я знал.
```

### `whoami` на localhost (после [[Миссия 3 — Призрак в проводах|миссии 3]])
```
[burunduk]: Хороший вопрос. Не только для терминала.
```

### ssh на localhost
```
[burunduk]: Ты уже здесь. Философский тупик.
```

### `exit` вместо `quit`
```
[burunduk]: Команда 'exit'. Как в настоящем терминале.
            Старая привычка? Или ты знаешь bash лучше,
            чем я думал?
```

### `help me`
```
[burunduk]: Это не Google, {handle}.
            Но если серьёзно — я здесь. 'hint' для подсказки.
```

## Призрачная history

### `history` на localhost (после нескольких миссий)
Среди команд игрока -- "призрачные" записи от burunduk'а:
```
  49  # [03:14 — session by B]
  50  # checking your system health
  51  # df -h && free -m && uptime
  52  # всё в порядке. спи спокойно.
```
Burunduk заходит на машину игрока ночью, проверяет здоровье системы, оставляет комментарии.
