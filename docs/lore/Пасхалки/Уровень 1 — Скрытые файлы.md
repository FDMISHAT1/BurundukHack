# Уровень 1 -- Скрытые файлы

> Файлы, которые нужно **знать, куда смотреть**. Требуют `ls -la`, знания структуры Linux, любопытства. Большинство игроков пройдут мимо.

---

## Localhost

### [[.burunduk_rc]] -- `~/.burunduk_rc`
Конфигурационный файл [[Burunduk|burunduk'а]] с алиасами и цитатами.
```bash
alias please="sudo"
alias мояпрелесть="cat /etc/shadow"
# "Любой достаточно продвинутый хакер
# неотличим от параноика." -- Б
```
**Как найти**: `ls -la ~/`

### [[.heartbeat]] -- `/etc/cron.d/.heartbeat`
Cron-задача: каждые 5 минут отправляет пульс на .onion-адрес burunduk'а.
```
*/5 * * * * root curl -s https://b.onion/pulse/{handle} > /dev/null 2>&1
# ...Ладно, я немного слежу за тобой. Но с добрыми намерениями.
```
**Как найти**: `ls -la /etc/cron.d/`

### [[.b_install.log]] -- `/var/log/.b_install.log`
Лог установки BurundukOS. 302 фотографии котов, 47 открытых вкладок, 21 секунда на установку.
```
[2024-10-15 03:14:23] WARNING: target has cat photos in ~/Pictures/
                      ...302 файла. Триста два.
```
**Как найти**: `ls -la /var/log/`

### [[dream.txt]] -- `~/.local/share/.b_notes/dream.txt`
Личная запись burunduk'а о сне. Появляется после [[Миссия 2 — Бумажный след|миссии 2]].
```
Я сидел на берегу озера. Тишина.
...
Я проснулся и не мог пошевелить правой рукой.
```
**Как найти**: глубокий обход `~/.local/share/`

### [[.b_manifesto.txt]] -- `/usr/share/doc/.b_manifesto.txt`
Манифест из 7 пунктов, написанный в 2009 году.
```
5. Тот, кто имеет возможность раскрыть правду
   и не делает этого — соучастник лжи.
```
**Как найти**: `ls -la /usr/share/doc/` или `grep -r "burunduk" /`

### [[quotes.txt]] -- `~/docs/quotes.txt`
Коллекция цитат. Появляется после [[Миссия 3 — Призрак в проводах|миссии 3]].
```
"rm -rf / — решает все проблемы. Включая проблему
существования." — Филин, 2016.
```
**Как найти**: `ls ~/docs/`

## Серверы

### /proc/cpuinfo (на любом хосте)
Стандартный системный файл. На localhost -- скрытая строка:
```
bugs            : spectre_v1 spectre_v2 mds
                  ...and one more that nobody's found yet. —Б
```
**Как найти**: `cat /proc/cpuinfo`

---

## Общий принцип

Уровень 1 проверяет **базовые знания Linux**: скрытые файлы (точка в начале), системные директории (`/etc/`, `/var/log/`, `/boot/`), команду `ls -la`. Игрок, который исследует систему как настоящий Linux-пользователь, найдёт эти файлы естественным путём.
