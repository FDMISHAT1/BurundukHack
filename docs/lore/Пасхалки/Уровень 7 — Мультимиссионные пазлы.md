| Порт 4471 | 44/14 = 3.14... |
| [[os-release]] | BUILD_DATE: `2024-10-15T03:14:07Z` |
| Git log (NovaTech) | Force-push: `2024-03-15 03:14:07` |

### Интерпретация
- 14 марта -- **Pi Day** (День числа пи)
- Может быть день рождения [[Burunduk|burunduk'а]]
- Может быть дата значимого события (начало пути? потеря кого-то?)
- **Никогда не подтверждается**. Burunduk не объясняет, почему это число для него важно

## Пазл 2: Координаты [[Синица|Синицы]]

Фрагменты координат разбросаны по разным миссиям:

| Миссия | Файл | Фрагмент |
|--------|------|----------|
| 1 (NovaTech) | /etc/hosts | `# 174.x — staging server (decommissioned)` |
| 2 (Crestfall) | Финансовый документ | `ref: -41.xxxx` |
| 3 (Irongate) | Лог | `longitude offset: 174.7762` |
| 4 (Vektora) | [[Threat Profile — burunduk]] | `Sinitsа — NZ, confirmed` |

### Полные координаты
**-41.2865, 174.7762** -- Веллингтон, Новая Зеландия. Где живёт [[Синица]].

### Смысл
[[Burunduk]] разбросал координаты единственного человека, с которым у него остались тёплые отношения, по всей инфраструктуре **противника**. Зачем?
- Тайное послание, которое только внимательный соберёт
- Способ быть рядом с теми, кого потерял
- Или ловушка: если Полог тоже соберёт -- [[Синица]] в опасности?

## Пазл 4: [[Лесная метафора]] -- единая символическая система

Если собрать информацию обо всех персонажах:

| Позывной | Животное | Символ |
|----------|----------|--------|
| [[Синица]] | Птица | Весна, надежда, обновление |
| [[Филин]] | Сова | Ночной охотник, точность, молчание |
| [[Ёж]] | Ёж | Защита, мягкость под иглами, уязвимость |
| [[КРОТ (Виктор)\|КРОТ]] | Крот | Подземная работа, слепота (не видит морали?) |
| [[Burunduk]] | Бурундук | Запасливость, скорость, незаметность |

Все позывные -- **лесные животные**.
- [[Нора (The Burrow)|Нора]] -- жилище. Лес.
- [[Полог (The Canopy)]] -- крона дерева. Лес.
- [[Операция ЖЁЛУДЬ]] -- семя дуба. Лес.

**Вся война** -- в метафорическом лесу, где маленькие лесные зверьки противостоят огромному дереву.

### Триггер
`echo "лес"`:
```
[burunduk]: ...Ты заметил. Конечно, ты заметил.
```

### Yggdrasil
В [[Миссия 5 — Полог|миссии 5]] один из серверов [[Полог (The Canopy)|Полога]] назван **Yggdrasil** -- мировое древо в скандинавской мифологии. Дерево, соединяющее все миры. Ядро сети Полога -- буквально мировое древо.
