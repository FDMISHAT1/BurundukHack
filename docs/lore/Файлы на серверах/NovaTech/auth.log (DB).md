# auth.log (DB)

> Лог аутентификации на DB-сервере [[NovaTech Solutions]]. Содержит записи о фантомных логинах с IP 10.99.0.77 (сеть [[Vektora Analytics]]) ровно в 03:00 с продолжительностью ровно до 03:14.

## Расположение

`/var/log/auth.log` на DB-сервере db-server (192.168.1.20)

## Содержимое файла

```
Nov 10 03:00:01 db-server sshd[4471]: Connection from 10.99.0.77 port 22
Nov 10 03:00:02 db-server sshd[4471]: Accepted key for root
Nov 10 03:00:03 db-server sshd[4471]: session opened for root
Nov 10 03:14:07 db-server sshd[4471]: session closed for root
...
Nov 12 03:00:01 db-server sshd[5102]: Connection from 10.99.0.77 port 22
Nov 12 03:00:02 db-server sshd[5102]: Accepted key for root
Nov 12 03:14:07 db-server sshd[5102]: session closed for root
```

## Скрытые паттерны

1. **IP 10.99.0.77** -- из подсети 10.99.0.0/24, которая является целевой сетью [[Миссия 4 — Крот|миссии 4]] ([[Vektora Analytics]])
2. **Каждые два дня, ровно в 03:00** -- автоматизированный сбор данных
3. **Сессия длится ровно до 03:14:07** -- 14 минут 7 секунд. [[Число 3-14|Число 3:14]] снова
4. **PID 4471** -- процесс SSH имеет номер [[Тикет 4471|4471]]. Совпадение? В этой игре совпадений не бывает
5. **Accepted key for root** -- аутентификация по ключу, не по паролю. Оператор Полога имеет прямой root-доступ

## Нарративная функция

- **Хлебная крошка к миссии 4**: если игрок заметит IP 10.99.0.77 и попытается подключиться до миссии 4:

```
Connection refused: 10.99.0.77 — host not found.

[burunduk]: Откуда ты знаешь этот адрес?
            ...
            Ты читал auth.log на сервере БД.
            Молодец. Серьёзно. Я бы на этом этапе
            не заметил.
            
            Этот адрес... потом. Всему своё время.
```

- **Навязчивое [[Число 3-14]]**: время 03:14 пронизывает всю игру -- лог установки, дневник [[КРОТ (Виктор)|КРОТ'а]], сессии здесь
- **Автоматизация**: Полог не заходит вручную -- это скрипт, который собирает данные с ретранслятора каждые 48 часов

## wtmp.txt (дублирующий лог)

На том же сервере `/var/log/wtmp.txt` содержит аналогичные данные в другом формате:

```
dbadmin  pts/0   192.168.1.10   Mon Nov 11 09:15 - 09:47
dbadmin  pts/0   192.168.1.10   Tue Nov 12 08:30 - 08:55
root     pts/1   10.99.0.77     Wed Nov 13 03:00 - 03:14
dbadmin  pts/0   192.168.1.10   Wed Nov 13 09:00 - 09:22
root     pts/1   10.99.0.77     Fri Nov 15 03:00 - 03:14
```
