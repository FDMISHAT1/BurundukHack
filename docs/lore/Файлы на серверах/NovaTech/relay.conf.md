# relay.conf

> Скрытый конфигурационный файл ретранслятора [[Полог (The Canopy)|Полога]], спрятанный в /tmp. Бонусная находка -- не требуется для прогресса миссии.

## Расположение

`/tmp/.relay.conf` на рабочей станции dev-workstation (192.168.1.10)

Файл начинается с точки (скрытый). Находится в /tmp, где его могут не искать. Нужно сделать `ls -la /tmp/` чтобы увидеть.

## Содержимое файла

```
# [ЗАШИФРОВАННАЯ КОНФИГУРАЦИЯ]
# relay_id: NT-7
# upstream: 10.20.30.15:4443
# protocol: custom-tls-1.3
# heartbeat: 240s
# data_exfil_path: /var/lib/mysql/customers.db
# — этот файл не должен здесь быть.
```

## Нарративная функция

- **Хлебная крошка**: upstream `10.20.30.15:4443` -- это адрес в сети [[Crestfall Financial]] ([[Миссия 2 — Бумажный след|миссия 2]])
- **Раскрытие**: показывает, что данные утекают через `/var/lib/mysql/customers.db` -- файл, замаскированный под базу клиентов
- **relay_id: NT-7** -- NovaTech является седьмым узлом ретрансляционной сети Полога
- **heartbeat: 240s** -- каждые 4 минуты сервер "пингует" upstream. Это объясняет ночную нагрузку из [[notes.txt (developer)]]
- **Комментарий "этот файл не должен здесь быть"** -- кто-то (оператор [[Полог (The Canopy)|Полога]]) оставил заметку для себя
