# known_hosts (developer)

> SSH known_hosts файл на рабочей станции [[NovaTech Solutions]]. Содержит закомментированную ссылку на сеть [[Vektora Analytics]] -- хлебную крошку к [[Миссия 4 — Крот|миссии 4]].

## Расположение

`/home/developer/.ssh/known_hosts` на рабочей станции dev-workstation (192.168.1.10)

Обычно игроки не проверяют `.ssh/`. Нужно знать структуру Linux-системы.

## Содержимое файла

```
192.168.1.20 ssh-rsa AAAAB3NzaC1yc2EAAAA...
192.168.1.1 ssh-rsa AAAAB3NzaC1yc2EAAAA...
# 10.99.0.1 — DO NOT CONNECT — V. will know
```

## Нарративная функция

- **Первые две строки**: обычные записи -- DB-сервер (192.168.1.20) и роутер (192.168.1.1)
- **Третья строка**: `10.99.0.1` -- шлюз сети [[Vektora Analytics]] из [[Миссия 4 — Крот|миссии 4]] (целевая сеть: 10.99.0.0/24)
- **"V. will know"**: "V." -- [[КРОТ (Виктор)|Виктор/КРОТ]]. Кто-то (оператор Полога? сам developer, не зная контекста?) знает, что подключение к этому адресу будет обнаружено
- **Хронологический эффект**: если игрок видит это в миссии 1 -- строка ничего не значит. Если вспомнит в миссии 4, когда получит целевую сеть 10.99.0.0/24 -- осознание: нити были видны с самого начала
