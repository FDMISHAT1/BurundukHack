# .burunduk_rc

> Скрытый конфигурационный файл, оставленный [[Burunduk|burunduk'ом]] на localhost. Алиасы, цитаты и юмор. Показывает человечную сторону burunduk'а.

## Расположение

`~/.burunduk_rc` на localhost (домашняя директория [[Игрок|игрока]])

Скрытый файл (начинается с точки). Нужно `ls -la ~/` чтобы увидеть.

## Содержимое файла

```bash
# Конфигурация, которую Б оставил для себя
# Не трогай. Или трогай. Мне всё равно.
# (На самом деле не всё равно. Не трогай.)

alias ll="ls -la"
alias cls="clear"
alias please="sudo"
alias мояпрелесть="cat /etc/shadow"

# "Любая достаточно продвинутая технология
# неотличима от магии." -- Артур Кларк
# "Любой достаточно продвинутый хакер
# неотличим от параноика." -- Б
```

## Нарративная функция

### Алиасы
- **`ll="ls -la"`** -- стандартный алиас опытного Linux-пользователя
- **`cls="clear"`** -- привычка из DOS/Windows. Burunduk когда-то пользовался Windows?
- **`please="sudo"`** -- юмор. Вежливый запрос root-прав. Классическая шутка из Linux-культуры
- **`мояпрелесть="cat /etc/shadow"`** -- отсылка к Голлуму/Толкиену. `/etc/shadow` -- файл с хешами паролей, "прелесть" хакера

### Цитаты
- **Артур Кларк** -- третий закон: "Любая достаточно продвинутая технология неотличима от магии"
- **Б** -- пародия: "Любой достаточно продвинутый хакер неотличим от параноика." Самоирония burunduk'а. Он знает, что его паранойя (шифрование, heartbeat, заметание следов) может выглядеть чрезмерной

### Тон
- **"Не трогай. Или трогай. Мне всё равно. (На самом деле не всё равно.)"** -- типичный стиль burunduk'а. Показная безразличность, за которой стоит забота
- Файл существует на машине **игрока** -- burunduk оставил свой конфиг, зная, что игрок может его найти
