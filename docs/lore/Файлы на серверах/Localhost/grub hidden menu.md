# grub hidden menu

> Скрытая запись загрузчика GRUB на localhost. Содержит пазл: пароль для recovery mode. Подсказка указывает на содержание [[Тикет 4471|тикета]], а не на его номер.

## Расположение

`/boot/grub/.hidden_menu` на localhost

Нужно додуматься проверить загрузчик. `/boot/grub/` -- не то место, куда заглядывают игроки.

## Содержимое файла

```
# GRUB hidden menu entry
# Added by: B
# Purpose: emergency recovery

menuentry "Recovery Mode — for B only" {
    set root=(hd0,1)
    linux /boot/vmlinuz-recovery root=/dev/sda1
    # password: тикет который всё начал
    # (и нет, это не "4471". подумай шире.)
}

# Подсказка: не номер. Содержание.
# Что было в тикете? Аномальный трафик.
# Пароль: anomaly
```

## Разгадка пазла

1. **"Тикет который всё начал"** -- [[Тикет 4471]]
2. **"Не 4471. Подумай шире."** -- не номер тикета, а его **содержание**
3. **"Что было в тикете? Аномальный трафик."** -- из [[Инсталлятор (завязка)|инсталлятора]]: "Аномальный исходящий трафик из бухгалтерской подсети"
4. **Пароль: `anomaly`** -- "аномалия"

### Триггер при вводе "anomaly"

Если игрок введёт `echo anomaly` или использует "anomaly" как пароль:

```
[burunduk]: ...Ты нашёл recovery menu в GRUB.
            И разгадал пароль.
            
            Это был тест. На случай, если я не смогу
            добраться до этой машины сам, а кто-то должен
            будет её восстановить.
            
            Теперь этот "кто-то" — ты.
```

## Нарративная функция

### Emergency recovery
- **"For B only"** -- burunduk создал аварийный вход для себя. Но из-за [[Burunduk#Болезнь|болезни]] может оказаться, что он не сможет им воспользоваться
- **"Теперь этот 'кто-то' -- ты"** -- передача контроля. Burunduk готовит [[Игрок|игрока]] к тому, что однажды придётся действовать без учителя
- **Пароль на основе смысла, не числа** -- характерно для burunduk'а: он ценит понимание, не запоминание

### Цепочка находок
Чтобы найти и разгадать:
1. Заглянуть в `/boot/grub/` (редкость)
2. Прочитать файл
3. Понять, что "4471" -- ложный след
4. Вспомнить содержание тикета из [[Инсталлятор (завязка)|вступления]]
5. Ввести пароль

Это пазл для [[Уровень 9 — Для единиц|0.1% игроков]].
