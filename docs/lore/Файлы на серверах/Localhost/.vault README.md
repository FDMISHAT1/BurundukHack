# .vault README

> README зашифрованной партиции на localhost. Содержит загадку: пароль -- первые буквы имён всех участников [[Нора (The Burrow)|Норы]]. Невозможно разгадать до [[Миссия 4 — Крот|миссии 4]].

## Расположение

`/opt/.vault/README` на localhost

Путь `/opt/.vault/` упоминается в [[.b_install.log]]: "Creating encrypted partition: /opt/.vault". Нужно сначала найти лог установки, потом проверить этот путь.

## Содержимое файла

```
Если ты нашёл этот файл — значит, ты читал логи.
Хорошая привычка. Не теряй её.

Этот раздел зашифрован. Внутри — инструменты,
которые я не положил в основной набор. Не потому
что ты их не заслужил. А потому что они опасны.

Пароль: первые буквы имён всех участников Норы,
в порядке их вступления. Без пробелов. В нижнем регистре.

Когда будешь готов — будешь знать.

--Б
```

## Разгадка пароля

Участники [[Нора (The Burrow)|Норы]] в порядке вступления:
1. **С**иница -- первая
2. **Ф**илин -- второй
3. **Ё**ж -- третий
4. **К**РОТ -- четвёртый
5. **{первая буква позывного игрока}** -- шестой (пятый не назван)

Пароль: **сфёк{буква}** (в нижнем регистре)

### Условия разгадки
- Нужно знать **всех** участников Норы -- это раскрывается постепенно через [[MSG 3 — О Норе]] и [[Миссия 4 — Крот]]
- Нужно знать **порядок вступления** -- из MSG 3: Синица "первая", Филин "второй", Ёж "третий"
- КРОТ раскрывается как "четвёртый" в миссии 4
- Игрок -- "шестой" (burunduk -- основатель, не вступал)
- **Пятый участник** -- загадка. См. [[Уровень 7 — Мультимиссионные пазлы]]: [[Дмитрий Волков]] может быть пятым

### Дизайн пазла
Пазл **невозможно** решить в начале игры. Burunduk знает это -- "Когда будешь готов -- будешь знать." Это приглашение вернуться позже, награда за внимательность к истории.
