# .heartbeat

> Скрытый cron-файл, установленный [[Burunduk|burunduk'ом]]. Каждые 5 минут отправляет "пульс" на сервер burunduk'а -- подтверждение, что система работает (и что [[Игрок|игрок]] жив).

## Расположение

`/etc/cron.d/.heartbeat` на localhost

Большинство игроков никогда не заглянут в `/etc/cron.d/`. Скрытый файл (точка в начале имени) -- двойная маскировка.

## Содержимое файла

```
# Pulse check — do not remove
# Installed by: B
# Purpose: if this file is deleted, I'll know something went wrong.
#
*/5 * * * * root curl -s https://b.onion/pulse/{handle} > /dev/null 2>&1
#
# Да, я слежу за тем, что система работает.
# Нет, я не слежу за тобой. Есть разница.
# ...Ладно, я немного слежу за тобой. Но с добрыми намерениями.
```

## Нарративная функция

### Техническая сторона
- **`*/5 * * * *`** -- каждые 5 минут
- **`root`** -- запускается от root (burunduk имеет полный контроль)
- **`curl -s https://b.onion/pulse/{handle}`** -- .onion-адрес (Tor). Burunduk принимает пульс через даркнет
- **`> /dev/null 2>&1`** -- вывод подавлен. Незаметный процесс

### Забота vs. контроль
- **"Я слежу за тем, что система работает"** -- техническая причина
- **"Я не слежу за тобой. Есть разница."** -- юридическая оговорка
- **"Ладно, я немного слежу за тобой. Но с добрыми намерениями."** -- честность. Типичный стиль burunduk'а: показная грубость -> оговорка -> правда

### Dead man's switch
В [[.b_install.log]] упоминается "Setting up dead man's switch". Heartbeat -- часть этого механизма. Если пульс прекращается, burunduk узнает, что:
- Система скомпрометирована
- Игрок в опасности
- Или просто удалил cron-файл (в этом случае -- "I'll know something went wrong")

### Связь с [[Эпилог|эпилогом]]
"Dead man's switch" сработает в конце игры, когда burunduk не сможет больше работать. Автоматическое [[Эпилог|последнее письмо]] отправится [[Игрок|игроку]].
