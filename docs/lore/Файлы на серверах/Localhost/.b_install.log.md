# .b_install.log

> Лог установки BurundukOS, который [[Burunduk]] "забыл" удалить. Скрытый файл в `/var/log/`. Содержит технические записи с личными комментариями -- включая замечание о 302 фотографиях котов.

## Расположение

`/var/log/.b_install.log` на localhost

Скрытый файл (начинается с точки). Нужно `ls -la /var/log/` чтобы увидеть.

## Нарративная функция

### Timestamp: [[Число 3-14|03:14:07]]
- Установка начинается в 03:14:07 -- навязчивое число burunduk'а
- Вся установка заняла **21 секунду** -- показывает мастерство burunduk'а

### Детали о машине [[Игрок|игрока]]
- **Dell Latitude 5520** -- типичный корпоративный ноутбук. Игрок работает в [[GlobeTech]]
- **Ubuntu 22.04** -- не Windows. Игрок уже знает Linux (хоть и базово)
- **47 открытых вкладок Firefox** -- бытовая деталь. "Кто так живёт?" -- юмор burunduk'а
- **302 фотографии котов** -- очеловечивание. [[Игрок]] -- обычный человек с котиками. Burunduk замечает это и комментирует

### Технические действия
- **Disabling telemetry** -- отключение слежки ОС
- **Patching kernel** -- укрепление ядра
- **Creating encrypted partition: /opt/.vault** -- ссылка на [[.vault README]]
- **Setting up dead man's switch** -- механизм, который сработает, если burunduk перестанет выходить на связь (используется в [[Эпилог|эпилоге]])

### Самоирония
- **"Не очень хорошо спрятал, видимо, раз ты это читаешь"** -- burunduk ожидал, что игрок найдёт. Или не ожидал, но рад
- **"Новый рекорд"** -- гордость за свою скорость
