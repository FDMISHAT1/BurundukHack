# SSH authorized_keys (КРОТ)

> Файл авторизованных SSH-ключей на рабочей станции [[КРОТ (Виктор)|КРОТ'а]]. Содержит закомментированный, но **не удалённый** ключ [[Burunduk|burunduk'а]]. За шесть лет.

## Расположение

`/home/v.admin/.ssh/authorized_keys` на сервере [[Vektora Analytics]]

## Содержимое файла

```
ssh-rsa AAAAB3Nza... v.admin@vektora
ssh-rsa AAAAB3Nza... canopy-master@core
# ssh-rsa AAAAB3Nza... burunduk@nowhere
# ^— старый ключ. Оставил. Не знаю зачем.
```

## Нарративная функция

### Три ключа -- три идентичности
1. **v.admin@vektora** -- рабочий ключ КРОТ'а в [[Vektora Analytics]]
2. **canopy-master@core** -- ключ от ядра [[Полог (The Canopy)|Полога]]. "master" -- высший уровень доступа
3. **burunduk@nowhere** -- ключ [[Burunduk|burunduk'а]]. `@nowhere` -- "ниоткуда". Burunduk не привязан к месту

### Закомментирован, но не удалён
- КРОТ **закомментировал** ключ (`#`), сделав его неактивным
- Но **не удалил**. За **шесть лет** (2018-2024)
- Комментарий: "Оставил. Не знаю зачем." -- КРОТ пишет это **для себя**. Никто другой не будет читать его authorized_keys
- Это говорит о нём больше, чем любой диалог

### Что это значит
Технически, удаление одной строки -- 3 секунды. КРОТ, руководитель техотдела [[Vektora Analytics]], мастер кибербезопасности, **оставил SSH-ключ бывшего противника** на своём рабочем сервере. Это не ошибка -- это выбор.

Варианты интерпретации:
- Сентиментальность. Ключ -- последняя физическая связь с учителем
- Подсознательная надежда. Что однажды burunduk придёт
- Саботаж. Оставить дверь приоткрытой на случай, если пожалеет о выборе

В контексте других находок ([[Дневник КРОТ'а]], [[Библиотека КРОТ'а]], [[Project Acorn Status]]) -- скорее всего все три одновременно.

### Геймплейный потенциал
Если игрок активирует ключ burunduk'а (раскомментирует) -- теоретически burunduk может подключиться к серверам КРОТ'а напрямую. Это может быть использовано в [[Миссия 5 — Полог|миссии 5]].
