# Филин

> *"rm -rf / -- решает все проблемы. Включая проблему существования."* -- Филин, 2016

## Базовая информация

| Поле | Значение |
|------|----------|
| Позывной | Филин |
| Роль в [[Нора (The Burrow)\|Норе]] | Участник |
| Период | ~2013-2017 |
| Статус | **Погиб**, Стамбул, 14 августа 2017 |
| Официальная причина | Автокатастрофа (мокрая дорога) |

## Характер

Резкий, точный, не терпел ошибок. Чёрный юмор. [[Burunduk]] цитирует его шутку про `rm -rf /` в [[quotes.txt]].

## Символизм

**Филин** -- ночной охотник, точность, молчание. Часть [[Лесная метафора|лесной метафоры]].

## Гибель

Официально -- автокатастрофа на трассе E-80 в Стамбуле. Мокрая дорога, грузовик.

[[Burunduk]] долго верил, что случайность. До [[Миссия 4 — Крот|миссии 4]].

### Правда

Убийство, организованное [[Полог (The Canopy)|Пологом]]. Грузовик оснащён дистанционным управлением рулём. Маршрут Филина выдан [[КРОТ (Виктор)|КРОТ'ом]], которому сказали, что это "пассивное наблюдение".

Полная документация: [[Гибель Филина (отчёт)]]

### Скрытая улика (пасхалка)

В файле `/tmp/.Xauthority` на DB-сервере ([[Миссия 1 — Первый контакт|миссия 1]]) зашит hex-код:

```
Filin. 2017. Istanbul. Not an accident.
```

[[Burunduk]] спрятал эту улику задолго до того, как отправил туда [[Игрок|игрока]]. См. [[Уровень 3 — CTF секреты#Xauthority]]
